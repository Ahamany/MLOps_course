# MLOps basic — домашние задания №1 и №2

Репозиторий с выполненными домашними заданиями по предмету **MLOps basic**: настройка Python-проекта и окружения, работа с линтером и проверкой типов, практика работы с Git.

## Структура проекта

```text
mlops/
├── src/
│   └── mlops/
│       └── __init__.py  # функция main и приветствие приложения
├── .python-version     # Python 3.12
├── conflict.txt        # учебный файл для разрешения конфликта Git
├── pyproject.toml      # метаданные, зависимости и команда запуска
├── uv.lock             # зафиксированные версии зависимостей
└── README.md
```

## Быстрый старт

Для работы нужны Git, Python 3.12 или новее и установленный [uv](https://docs.astral.sh/uv/).

```bash
git clone https://github.com/Ahamany/MLOps_course.git
cd MLOps_course
uv sync --locked
uv run mlops
```

Ожидаемый вывод:

```text
Hello from mlops!
```

`uv sync --locked` создаёт локальное окружение `.venv` и устанавливает зависимости по `uv.lock`. Активация окружения вручную не требуется: команды выполняются через `uv run`.

## ДЗ №1. Окружение, Ruff и ty

Создан Python-пакет `mlops` со структурой `src/mlops`. В `pyproject.toml` описаны метаданные проекта, требование `Python >=3.12`, сборка через `uv_build` и консольная команда `mlops`, вызывающая функцию `main`.

В зависимости проекта добавлены:

- `requests` — библиотека для HTTP-запросов;
- `ruff` — линтер и форматтер Python-кода;
- `ty` — инструмент проверки типов.

Версия Python для окружения указана в `.python-version`, версии зависимостей зафиксированы в `uv.lock`. Ruff и ty используются с настройками по умолчанию.

Проверка кода:

```bash
uv run ruff check .
uv run ruff format --check .
uv run ty check
```

Для применения форматирования:

```bash
uv run ruff format .
```

## ДЗ №2. Работа с Git

В истории репозитория отработаны создание веток, коммиты, слияние изменений и ручное разрешение конфликта.

- Созданы ветки `main`, `develop`, `feature` и `bar`.
- В ветке `feature` добавлен учебный файл; изменения объединены с основной веткой merge-коммитом `f5c58fe` (`Merge branch 'feature'`). Учебные файлы затем удалены коммитом `4ec487d`.
- В `conflict.txt` внесены изменения в разных ветках: коммиты `79687e4` и `04ecb50`.
- Конфликт слияния разрешён вручную; результат сохранён merge-коммитом `078bef7` (`merge resolve`). Файл `conflict.txt` оставлен как результат упражнения.

Посмотреть историю и ветки:

```bash
git log --all --graph --oneline --decorate
git branch -a
```
