# MLOps basic — домашние задания №1 и №2

Репозиторий с выполненными домашними заданиями по предмету **MLOps basic**. В рамках работ настроено окружение Python-проекта, подключены инструменты проверки кода и выполнены упражнения по работе с Git.

## ДЗ №1. Окружение и проверка кода

- Создан Python-пакет `mlops` со структурой `src/`.
- Настроено управление окружением и зависимостями через **uv**.
- В `.python-version` указана версия Python **3.12**, зависимости зафиксированы в `uv.lock`.
- Установлены **Ruff** для проверки и форматирования кода, **ty** для проверки типов и библиотека **requests**.
- В `pyproject.toml` описаны параметры сборки пакета и консольная команда `mlops`.

### Запуск проекта

Для работы необходимы Git и установленный [uv](https://docs.astral.sh/uv/).

```bash
git clone https://github.com/Ahamany/MLOps_course.git
cd MLOps_course
uv sync --locked
uv run mlops
```

Команда `uv sync --locked` устанавливает зависимости из `uv.lock` в локальное окружение. При запуске приложение выводит:

```text
Hello from mlops!
```

### Проверка кода

```bash
uv run ruff check .
uv run ruff format --check .
uv run ty check
```

Для автоматического форматирования:

```bash
uv run ruff format .
```

## ДЗ №2. Работа с Git

Выполнены упражнения с ветками, коммитами и слияниями:

- создание и использование веток `main`, `develop`, `feature` и `bar`;
- добавление и удаление учебных файлов;
- слияние изменений из ветки `feature`;
- изменение файла `conflict.txt` в разных ветках;
- ручное разрешение конфликта слияния.

Результат разрешения конфликта сохранён в `conflict.txt` и merge-коммите `078bef7` (`merge resolve`). Слияние ветки `feature` отражено в коммите `f5c58fe`.

Просмотр истории выполнения:

```bash
git log --all --graph --oneline --decorate
git branch -a
```
